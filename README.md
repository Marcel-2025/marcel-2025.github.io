# Flondy Dev. – Sammel-Repo für alle Landingpages

Seit 20.11.2026 liegen alle Landingpages und Datenschutzseiten der Flondy-Apps hier, jede in **einem eigenen Ordner**.

## Aufbau
- `<Ordner>/` = eine Landingpage, z. B. `Metro-Dash/` → https://marcel-2025.github.io/Metro-Dash/
- Die Ordnernamen sind **genau die alten Repo-Namen**. Dadurch bleiben alle Adressen gleich, auch die Datenschutz-Links in der Play Console und im App Store.
- `nutzungsbedingungen.html` – gilt für alle Apps (EN: `terms.html`).
- `datenschutz.html` – Übersicht aller Datenschutzerklärungen.
- `flondy-icons/` – App-Icons für den Flondy Store und Flondy.Dev.
- `app-ads.txt` – nicht anfassen.

## Eine Landingpage aktualisieren
Nur den Ordner der App ändern oder überschreiben. Die anderen Ordner bleiben unberührt.

## Umstellung
Solange im alten Einzel-Repo GitHub Pages noch an ist, zeigt GitHub die alte Seite (das Projekt-Repo hat Vorrang). Erst nach „Settings → Pages → Source: None“ im alten Repo übernimmt der Ordner hier. Die Adresse bleibt dabei gleich.
